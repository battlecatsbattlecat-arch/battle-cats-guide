貓咪大戰爭攻略網站

專案目標

建立以貓咪大戰爭為主題的攻略與遊戲資料網站，初期以繁體中文（台灣）玩家為主要使用者，未來支援多語言與不同地區版本。

核心功能

* 關卡攻略與攻略影片
* 角色與敵人資料庫
* 玩家角色庫（Box）
* 根據玩家持有角色推薦適合的攻略
* DPS 與遊戲數據計算工具

語言與地區策略

* 初期以繁體中文（台灣）作為主要介面語言。
* 架構從一開始就預留多語言支援。
* 未來可擴充日文、英文、韓文等語言。
* 語言與遊戲地區版本必須分開管理。
* 角色名稱、關卡名稱及說明文字應支援多語言。
* 不同地區的遊戲數值、角色推出狀態與關卡開放狀態必須分開記錄。
* 不可因為某筆資料有日文名稱，就直接判定它屬於日本版限定內容。

資料品質原則

* 以台灣版遊戲資料作為初期主要基準。
* 日本版資料可作為輔助參考，但不可直接當作台灣版資料。
* 不確定的資料必須標示未知，不可自行推測。
* 所有重要資料都應保留來源、版本與驗證紀錄。

開發原則

* 優先採用簡單、可維護的實作。
* 避免過度設計，但不得犧牲未來擴充所需的基本架構。
* 所有重要修改應保留版本紀錄。
* 網站 UI 與文件以繁體中文（台灣）為主，必要技術名詞保留英文。
